Four taskbar modes & native sparkline hover cards

Unedited Windows 11 captures. System counters sample every 2 seconds on demand, and optional vendor DLLs (pdh.dll, dxgi.dll, nvml.dll, amdadlx64.dll, ControlLib.dll, iphlpapi.dll) stay unloaded whenever disabled.

CPU & RAM

GetSystemTimes load, RAPL watts, and PawnIO read-only Intel MSR / AMD Ryzen 17h–1Ah SMN temperature, plus GlobalMemoryStatusEx RAM GB.

GPU, Clocks & VRAM

Auto-picks discrete GPUs via DXGI. Reads load, °C, core/VRAM MHz clocks, board watts (NVML / ADLX / IGCL), and dedicated VRAM %/GB.

NVMe Storage

Zero-admin drive temperatures via IOCTL_STORAGE_QUERY_PROPERTY, queue utilization %, read/write MB/s, and free/total TB capacity.

Network & Laptop Battery

Read-only design, SmartScreen & signed updates

  • Read-only drivers across 122 files Every driver matches strictly by VID:PID or unique HID/RFCOMM/BLE profile and never alters DPI, lighting, macros, or firmware.
  • Isolated PawnIO temperature helper The taskbar app runs unprivileged. Only when CPU temperature is enabled does TaskbarVitalsTemp.exe read Intel MSRs or SHA-256 verified AMD SMN registers via PawnIO.
  • SmartScreen vs ECDSA P-256 updates First-time GitHub installers are unsigned open-source binaries (select More info → Run anyway or build from source). Official auto-updates validate SHA256SUMS.txt.sig offline via Windows BCrypt before running.
  • Zero cloud telemetry & local history 30-day discharge logs, 365-day wear stats, device aliases, and ignored IDs remain strictly local on your machine. Only two things touch the network: the speed test (Cloudflare, only when you click it) and the update check (GitHub, can be turned off). No usage data is sent.

CLI options & Local JSON Pipe

Run from PowerShell or Command Prompt; stdout stays in English for reliable device issue reports.

TaskbarVitals.exe --list
Print detected peripherals and battery levels, then exit.
TaskbarVitals.exe --json
Emit peripheral readings as a structured JSON array.
TaskbarVitals.exe --text
Single-line status summary for YASB / Rainmeter widgets.
TaskbarVitals.exe --dump
Inspect HID, USB, Bluetooth & AirPods AAP paths; saves a report in %TEMP%.
TaskbarVitals.exe --events
Stream receiver HID wake push events for 60 seconds.
PowerShell — Local JSON pipe (\\.\pipe\TaskbarVitals) 
$pipe = [System.IO.Pipes.NamedPipeClientStream]::new('.', 'TaskbarVitals', 'In')
$pipe.Connect(1000)
$snap = ([System.IO.StreamReader]::new($pipe)).ReadToEnd() | ConvertFrom-Json
$snap.devices; $snap.system
