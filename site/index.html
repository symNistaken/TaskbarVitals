Built read-only and verified offline

  • Read-only peripheral queries Drivers in src/drivers/ match strictly by VID:PID or unique vendor HID collections and never alter DPI, lighting, macros, or firmware.
  • Isolated CPU temperature helper The main app runs unprivileged. Only when CPU temperature is enabled, TaskbarVitalsTemp.exe reads MSRs 0x1A2 & 0x1B1 via PawnIO and publishes numbers over read-only shared memory.
  • ECDSA P-256 signed updates Official Windows updates verify SHA256SUMS.txt.sig offline using Windows BCrypt against the maintainer's public key before offering installation.
  • Zero telemetry & local history Battery history (24h / 7d / 30d), device aliases, and thresholds stay strictly on your PC under %LOCALAPPDATA%\WirelessBattery.

CLI & JSON automation

Run from Command Prompt or PowerShell; diagnostics stay in English so you can paste them directly into device issues.

TaskbarVitals.exe --list
Print detected devices and current battery levels, then exit.
TaskbarVitals.exe --json
Output structured JSON readings for scripts and Rainmeter/widgets.
TaskbarVitals.exe --dump
Print HID collections, USB, and Bluetooth IDs; saves report to %TEMP%.
TaskbarVitals.exe --report
Launch the prefilled GitHub device support assistant.
TaskbarVitals.exe --demo
Display synthetic sample devices without recording battery history.
